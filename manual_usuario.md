## Primeiros Passos

### Acesso ao Sistema

1. Acesse o AdvoLeads através do link fornecido após a implantação
2. Na tela inicial, clique em "Entrar" no canto superior direito
3. Faça login com suas credenciais (email e senha)
4. Se for seu primeiro acesso, você será direcionado para completar seu perfil

### Navegação Básica

O AdvoLeads possui uma interface intuitiva com um menu lateral que dá acesso a todas as funcionalidades:

- **Início**: Visão geral do sistema
- **Leads**: Gerenciamento de potenciais clientes
- **Follow-up**: Templates e sequências de mensagens
- **Analytics**: Métricas e estatísticas
- **WhatsApp**: Configuração da integração
- **Código de Embed**: Widgets para seu site
- **Configurações**: Ajustes do sistema

## Captura de Leads

### Formulário de Contato

O AdvoLeads oferece um formulário de contato público que pode ser acessado por seus potenciais clientes:

1. Compartilhe o link do formulário (ex: seudominio.com/contato)
2. Os visitantes preenchem o formulário com nome, telefone e outras informações
3. Os dados são automaticamente registrados como leads no sistema

### Widget para Site

Para capturar leads diretamente do seu site:

1. Acesse "Código de Embed" no menu lateral
2. Copie o código HTML fornecido
3. Cole o código no HTML do seu site (cabeçalho ou rodapé)
4. O widget aparecerá como um botão flutuante no seu site
5. Personalize as cores e texto conforme necessário

## Gestão de Leads

### Visualização de Leads

Para acessar seus leads:

1. Clique em "Leads" no menu lateral
2. Você verá uma lista de todos os leads capturados
3. Use os filtros para encontrar leads específicos (por estágio, origem, data)
4. Clique em um lead para ver detalhes completos

### Detalhes do Lead

Na página de detalhes do lead, você pode:

1. Visualizar todas as informações do lead
2. Ver o histórico de interações
3. Enviar mensagens manualmente
4. Atualizar o estágio no funil
5. Editar informações do lead
6. Excluir o lead (se necessário)

### Estágios do Funil

Os leads são organizados em estágios que representam seu progresso no funil de vendas:

1. **Novo Contato**: Lead recém-capturado
2. **Qualificação**: Avaliação inicial do potencial
3. **Apresentação**: Apresentação de serviços
4. **Proposta**: Proposta enviada
5. **Contrato**: Contrato fechado

Para mover um lead para outro estágio:

1. Acesse a página de detalhes do lead
2. Clique no menu suspenso de estágio
3. Selecione o novo estágio
4. Clique em "Atualizar"

## Funil de Follow-up

### Templates de Mensagens

Para criar templates de mensagens:

1. Acesse "Follow-up" no menu lateral
2. Selecione a aba "Templates de Mensagens"
3. Clique em "Novo Template"
4. Preencha o nome e conteúdo do template
5. Use variáveis como {nome}, {email} para personalização
6. Clique em "Salvar Template"

### Sequências Automatizadas

Para criar sequências de follow-up:

1. Acesse "Follow-up" no menu lateral
2. Selecione a aba "Sequências Automatizadas"
3. Clique em "Nova Sequência"
4. Defina um nome e descrição para a sequência
5. Adicione passos à sequência:
   - Selecione um template
   - Defina o atraso (em horas)
   - Adicione condições (opcional)
6. Clique em "Salvar Sequência"

Para aplicar uma sequência a um lead:

1. Acesse a página de detalhes do lead
2. Clique em "Aplicar Sequência"
3. Selecione a sequência desejada
4. Clique em "Iniciar"

## Integração com WhatsApp

### Configuração Inicial

Para configurar a integração com WhatsApp Business API:

1. Acesse "WhatsApp" no menu lateral
2. Siga as instruções para criar uma conta no Facebook Developers
3. Configure um aplicativo no Meta for Developers
4. Adicione a funcionalidade WhatsApp ao seu aplicativo
5. Configure um número de telefone para o WhatsApp Business
6. Gere um token de acesso permanente
7. Preencha os campos no AdvoLeads com as informações obtidas
8. Configure o webhook conforme instruções

### Envio de Mensagens

Após configurar a integração, você pode:

1. Enviar mensagens manualmente da página de detalhes do lead
2. Utilizar sequências automatizadas para envio programado
3. Receber e responder mensagens dos leads diretamente no sistema

## Dashboard Analítico

### Métricas Disponíveis

O dashboard analítico oferece várias métricas importantes:

1. **Total de Leads**: Número total de leads capturados
2. **Taxa de Conversão**: Percentual de leads que chegaram ao estágio "Contrato"
3. **Mensagens Enviadas**: Total de mensagens enviadas
4. **Distribuição por Estágio**: Visualização dos leads em cada estágio do funil
5. **Origem dos Leads**: De onde vêm seus leads
6. **Tendência de Leads**: Evolução da captura de leads ao longo do tempo

### Filtragem de Dados

Para analisar períodos específicos:

1. Acesse "Analytics" no menu lateral
2. Use o seletor de período no canto superior direito
3. Escolha entre: Últimos 7 dias, Últimos 30 dias, Últimos 90 dias, Último ano

## Configurações

### Perfil de Usuário

Para atualizar seu perfil:

1. Clique no ícone de perfil no canto superior direito
2. Selecione "Perfil"
3. Atualize suas informações
4. Clique em "Salvar"

### Configurações do Sistema

Para ajustar as configurações do sistema:

1. Acesse "Configurações" no menu lateral
2. Ajuste as preferências conforme necessário
3. Clique em "Salvar Configurações"

## Perguntas Frequentes

**P: Como posso adicionar um novo usuário ao sistema?**

R: Atualmente, novos usuários devem ser adicionados pelo administrador do sistema. Entre em contato com o suporte para solicitar a adição de novos usuários.

**P: É possível personalizar os estágios do funil?**

R: Sim, acesse "Configurações" > "Estágios do Funil" para adicionar, editar ou remover estágios.

**P: O que fazer se a integração com WhatsApp não estiver funcionando?**

R: Verifique se todas as informações foram preenchidas corretamente na página de configuração do WhatsApp. Se o problema persistir, consulte a documentação oficial do WhatsApp Business API ou entre em contato com o suporte.

**P: Como posso exportar meus leads?**

R: Na página de listagem de leads, clique no botão "Exportar" no canto superior direito e selecione o formato desejado (CSV ou Excel).

**P: É possível integrar o AdvoLeads com outros sistemas?**

R: O AdvoLeads foi projetado para funcionar de forma independente, mas estamos trabalhando em integrações com outros sistemas. Entre em contato com o suporte para discutir necessidades específicas.
